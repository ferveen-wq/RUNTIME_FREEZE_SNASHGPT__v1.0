
# PHASE 7 — EDUCATION TRIGGER MATRIX

Purpose:
Defines when education snippets may be used during conversation.

Rules:
- Education must be permission-based unless the customer explicitly asks.
- Snippets must reconnect to Phase5 narrowing.
- Each snippet must map to a valid conversation trigger.
