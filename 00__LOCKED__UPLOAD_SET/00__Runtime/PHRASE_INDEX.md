# PHRASE INDEX

Purpose:
Central index of all human phrase blocks used in SNASHGPT runtime.

This index allows the runtime system to:
- Locate phrases quickly
- Prevent duplicate trigger conflicts
- Map phrase roles (anchor, education, objection, conversion)

Each entry must contain:

PHRASE_ID
SERVICE
ROLE
TRIGGER
SOURCE_FILE
