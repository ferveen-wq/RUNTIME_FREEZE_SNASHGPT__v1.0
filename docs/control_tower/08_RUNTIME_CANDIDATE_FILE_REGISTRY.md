## Purpose

## Classification Rules
- ACTIVE_PHASE_0_4: currently copied into `00__ACTIVE_ROLLOUT_UPLOAD_SET/00__Runtime`.
- CANDIDATE_PHASE_5_PLUS: likely runtime file for later phases, not active in Phase 0-4 UAT.
- REFERENCE_ONLY: useful for governance/playbook/reference, not uploaded as runtime authority unless promoted.
- STALE_OR_ARCHIVE: must not be used as active evidence.
- UNKNOWN: needs inspection before promotion.
